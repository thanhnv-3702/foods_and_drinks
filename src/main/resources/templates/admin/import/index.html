File CSV phải có dòng tiêu đề (header) ở dòng đầu, mã hóa UTF-8. Cột tham chiếu dùng tên (Team/Position) hoặc email (User/Leader/Member).

Positions

Cột: Name, Abbreviation

Skills

Cột: Name, Level, UsedYearNumber, UserEmail

Teams

Cột: Name, Description, LeaderEmail

Users

Cột: Name, Email, Birthday, Role, TeamName, PositionName, Password, Skills
Skills dạng name|level|years; name|level|years. Password trống → mặc định Password@123.

Projects

Cột: Name, Abbreviation, StartDate, EndDate, TeamName, LeaderEmail, MemberEmails
MemberEmails ngăn cách bằng ;
